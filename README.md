# ☕ Starbucks Sales Dashboard | Power BI

## 📌 Project Overview
This project is an interactive Power BI dashboard developed to analyze Starbucks sales performance. The dashboard provides insights into sales trends, product performance, customer purchasing behavior, and store-level performance, enabling data-driven business decisions.

---

## 🎯 Objectives
- Analyze overall sales performance.
- Track key business KPIs.
- Identify top-performing products and categories.
- Monitor monthly and daily sales trends.
- Compare store performance.
- Provide interactive filtering for better analysis.

---

## 📊 Dashboard Features
- Total Sales
- Total Orders
- Average Order Value
- Sales Trend Analysis
- Product Category Analysis
- Store Performance
- Peak Sales Hours
- Monthly & Daily Sales Comparison
- Interactive Slicers and Filters

---

## 🛠️ Tools & Technologies
- Power BI
- Power Query

- Data Modeling
- Data Visualization

## 📈 Key Insights
- Identified the highest revenue-generating products.
- Analyzed sales trends across different months.
- Compared performance across store locations.
- Tracked customer purchasing patterns.
- Monitored important business KPIs in a single dashboard.

---

## 📂 Dataset
The dataset contains Starbucks transaction data, including:
- Transaction Date
- Store Location
- Product Category
- Product Name
- Quantity Sold
- Unit Price
- Sales Amount
